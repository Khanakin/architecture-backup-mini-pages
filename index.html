Personal desktop backup utility

Architecture Backup Mini

Architecture Backup Mini is a private-use desktop utility for creating encrypted, versioned backups of a project selected by its owner. It runs on the owner's Mac mini and uses the owner's Google Drive as the backup destination.

What it does

  • Reads the selected local project and encrypts each backup before upload.
  • Creates and accesses backup files belonging to this application in Google Drive.
  • Downloads uploaded backup files and checks restoration, file integrity and the project Git repository.

Google Drive access

The utility requests only https://www.googleapis.com/auth/drive.file. It does not request access to all existing Drive documents. Access is granted by the owner through Google's consent screen.

Recovery keys

The permanent private recovery key is kept separately by the owner and is not uploaded to Google Drive or this website. A temporary verification key is created in memory for a backup run. Recovery still requires the separately held permanent key.

Privacy and contact

Read the privacy policy and terms of use. Public technical questions can be submitted through the project issue tracker. Do not post documents, credentials or keys.
