Privacy policy

This policy describes Architecture Backup Mini, a desktop backup utility intended for its owner's personal use. This website is an informational page and does not provide a sign-in form or accept project documents.

Google data accessed

After the owner grants consent, the utility uses the Google Drive drive.file permission to create, read and manage files created by or explicitly authorized for this application. Its intended use is to store encrypted backup archives and accompanying technical receipts in an application-owned folder.

Data use and transfer

Selected local project files are encrypted locally before upload. Google Drive receives encrypted archives and technical metadata such as snapshot names, dates, file sizes and checksums. Archives are downloaded to the owner's computer to verify restoration. The utility does not use project documents or Google user data for advertising, sale, or training AI models, and does not share them with other people.

Google processes data as the selected cloud storage provider, under the owner's Google account and Google's applicable terms and privacy policy. The application does not operate a separate backend that receives backup contents.

Credentials and recovery keys

Google authorization credentials remain in a local, access-restricted configuration on the owner's Mac mini, outside the backed-up project. They are not included in backup archives or this website. The permanent private recovery key remains separately held by the owner. A one-run verification key is generated in memory and is not intentionally saved to a file by the utility.

Retention, deletion and revocation

Backup versions remain until the owner chooses to delete them. The utility does not automatically delete older cloud versions. The owner can delete backup files in Google Drive and revoke the application's access in Google Account security settings. Revoking access stops future authorized operations; it does not itself delete files already stored in Drive or local copies.

Website and contact

This site includes no analytics, advertising scripts, forms or application login. GitHub Pages hosts these public documents and may process ordinary web request data under GitHub's privacy statement. For non-confidential technical questions, use the issue tracker. Do not submit credentials, recovery keys or private project data.

Limited use

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
