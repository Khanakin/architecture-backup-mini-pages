Terms of use

Architecture Backup Mini is a utility for its owner's personal backup workflow. It is not a public storage service and this website does not create user accounts or accept uploads.

Authorized use

Use the utility only with local files and a Google account you own or are authorized to manage. Grant access through Google's normal authorization screen. The application is intended to access only its own backup files using the limited Drive permission described in the privacy policy.

Recovery responsibilities

The owner keeps the permanent recovery key separately and checks successful backup and restoration receipts. Losing that key can make archives unrecoverable. A scheduled job alone does not prove that a backup has succeeded.

Operation

Backup operations require the Mac mini to be running with the required user session, available disk space, an Internet connection and valid Google authorization. Sleep, revoked authorization or provider limits can interrupt operations. The utility does not automatically start restored projects or modify unrelated working services.

Storage and changes

Google Drive storage remains subject to the owner's Google plan and provider terms. Older backup versions are retained until the owner deletes them. Technical questions can be raised in the issue tracker without private data.
